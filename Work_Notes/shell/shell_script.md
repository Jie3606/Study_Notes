```makefile
$0 : 脚本名
$0-$9: 脚本的参数
$@ ($*) : 所有参数
$# : 参数个数
$? : 前一个命令的返回值
$$ : 当前脚本的识别码
!! : 完整的上一条命令(包括参数)
$_ : 上一条命令的最后一个参数

$* 会将所有参数视为一个单一的字符串，而 $@ 会将每个参数视为一个独立的字符串,这意味着当参数包含空格时，$* 可能会导致问题，而 $@ 则不会。
```

```Makefile
hey : one two
    echo $@ 输出hey
    echo $? 输出比目标更新的所有先决条件
    echo $n 输出所有先决条件
```

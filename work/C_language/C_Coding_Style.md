# C 语言编码规范

## 1. 文件结构

- **文件命名**：使用小写字母，并用下划线分隔单词。文件名应具有描述性，反映其用途。
  - 示例：`my_module.c`，`my_module.h`

- **头文件**：使用头文件保护符防止多次包含。
  ```c
  #ifndef MY_MODULE_H
  #define MY_MODULE_H

  // 声明

  #endif // MY_MODULE_H
  ```

## 2. 代码格式

- **缩进**：每个缩进级别使用 4 个空格。不要使用制表符。

- **行长度**：限制每行不超过 80 个字符。

- **大括号**：将开括号放在控制语句的同一行。闭括号应与开头语句对齐。
  ```c
  if (condition) {
      // 代码
  } else {
      // 代码
  }
  ```

## 3. 命名约定

- **变量**：使用 `snake_case` 的描述性名称。对循环索引使用简短名称。
  - 示例：`int item_count;`，`int i;`

- **函数**：使用 `snake_case` 的描述性名称。函数名应为动词或动词短语。
  - 示例：`void calculate_total();`

- **常量**：对常量和宏使用 `UPPER_CASE` 并用下划线分隔。
  - 示例：`#define MAX_BUFFER_SIZE 1024`

## 4. 注释

- **块注释**：使用块注释描述代码的整体目的和复杂逻辑。
  ```c
  /*
   * 此函数计算总价
   * 包括税和折扣。
   */
  ```

- **行内注释**：谨慎使用行内注释来解释不明显的代码。
  ```c
  int total = subtotal + tax; // 将税加到小计
  ```

## 5. 函数

- **函数长度**：保持函数简短并专注于单一任务。理想情况下，函数不应超过 50 行。

- **参数传递**：对不应修改的参数使用 `const`。通过引用传递大型结构。

## 6. 错误处理

- **返回值**：使用返回值指示成功或失败。使用 `enum` 或 `#define` 定义错误代码。

- **断言**：使用断言在开发过程中捕获编程错误。
  ```c
  assert(pointer != NULL);
  ```

## 7. 内存管理

- **动态内存**：始终检查内存分配函数的结果。在不再需要时释放分配的内存。
  ```c
  int *array = malloc(size * sizeof(int));
  if (array == NULL) {
      // 处理分配失败
  }
  free(array);
  ```

## 8. 可移植性

- **标准库**：使用标准库和函数以提高可移植性。

- **数据类型**：使用 `<stdint.h>` 中的固定宽度数据类型以提高可移植性。
  - 示例：`int32_t`，`uint64_t`

## 9. 其他

- **预处理指令**：保持预处理指令简单，避免复杂逻辑。

- **包含顺序**：按以下顺序包含头文件：相关头文件、标准库头文件、第三方库头文件和项目头文件。

遵循这些规范可以确保您的 C 代码具有可读性、可维护性，并在不同项目中保持一致性。

# 多处理器编程：从入门到放弃

**背景回顾**：“操作系统玩具” 给出了理解操作系统的新视角：操作系统是状态机的管理者。因为在 `sys_sched()` 之后操作系统拥有随机选择状态机执行的权力，因此也带来了并发性。操作系统是世界上最早的并发程序。

**本讲内容**：多线程编程模型、线程库，以及并发带来的巨大麻烦。

### **多个共享内存的状态机**

- C 语言状态机的多个线程
    - 共享所有全局变量
    - 独立的栈帧列表
- 汇编语言状态机的多个线程
    - 共享一个地址空间
    - 独立的寄存器 (SP 指向不同内存位置)

### 状态迁移

- 选择**任意一个线程**执行一步

### Mosaic 状态机

- “heap” 是共享内存

- ```
    sys_sched
    ```
    主动随机切换线程

    - 单处理器系统：中断会引起切换
        - (这就是为什么死循环不能把机器卡死)
    - 多处理器系统：真正同时执行
        - 相当于无时不刻在切换
